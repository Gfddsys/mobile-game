# คู่มือใส่งานภาพ (Art Guide)

เกมนี้วาดภาพ placeholder ด้วยโค้ดทั้งหมด ศิลปินเปลี่ยนภาพได้โดย **ไม่ต้องแก้โค้ดและไม่ต้องตั้งค่าใน Unity เอง**:
วางไฟล์ PNG ชื่อเดียวกับภาพเดิมลงในโฟลเดอร์ `Assets/_Project/Resources/Sprites/` แล้ว Unity จะตั้งค่าให้อัตโนมัติ

## ขั้นตอน (5 ขั้น)

1. เปิดโปรเจกต์ใน Unity แล้วกดเมนู **Turtle Blaster ▸ Art ▸ 1. Export Placeholder Sprites (templates)**
   ได้ภาพต้นแบบทุกชิ้นที่ `Assets/_Project/Art/Placeholders/` และตารางขนาดที่ `Art/Placeholders/SPRITES.md`
2. ก๊อปไฟล์ต้นแบบที่จะวาดใหม่ ไปไว้ใน `Assets/_Project/Resources/Sprites/` (เมนู **Art ▸ 3. Show Art Override Folder** เปิดโฟลเดอร์ให้)
3. วาดทับในโปรแกรมที่ถนัด (Aseprite, Photoshop, Krita ฯลฯ) แล้ว **เซฟทับชื่อเดิม** เป็น PNG พื้นหลังโปร่งใส
4. กลับเข้า Unity ภาพจะ import อัตโนมัติ แล้วกด Play ดูได้เลย
5. กดเมนู **Art ▸ 2. Validate Art Overrides** เพื่อเช็กว่าชื่อไฟล์ถูกและสัดส่วนถูก (ดูผลใน Console)

ถ้าอยากกลับไปใช้ภาพเดิม แค่ลบไฟล์นั้นออกจาก `Resources/Sprites/`

## กฎ 3 ข้อ

| กฎ | เหตุผล |
|---|---|
| **ชื่อไฟล์ต้องตรงเป๊ะ** (ตัวพิมพ์เล็ก เช่น `cone.png`) | ชื่ออื่นเกมไม่ใช้ (Validate จะเตือน) |
| **รักษาสัดส่วนเดิม** วาดขนาดเท่าเดิมหรือคูณจำนวนเต็ม เช่น `turtle.png` 26×20 → 52×40 หรือ 104×80 | ระบบปรับ Pixels Per Unit ให้ขนาดในเกมเท่าเดิมเสมอ ถ้าสัดส่วนเพี้ยน ภาพจะยืดหรือเยื้อง |
| **วางตำแหน่งตัวภาพในกรอบให้เหมือนต้นแบบ** | จุดยึด (pivot) และกล่องชน (hitbox) อิงจากตำแหน่งเดิม เช่น กรวยต้องให้ฐานอยู่ขอบล่างของภาพ ไม่งั้นจะลอยหรือจมพื้น |

สิ่งที่ระบบตั้งให้อัตโนมัติ: Sprite, Filter = Point (คมแบบพิกเซล), ไม่บีบอัด, ไม่มี mipmap, pivot เท่าต้นแบบ, ขนาดในเกมเท่าต้นแบบ, ขอบ 9-slice ของ UI

## สิ่งที่เปลี่ยนด้วยภาพอย่างเดียวไม่ได้ (ต้องแก้โค้ด)

| อยากทำ | ต้องแก้ที่ |
|---|---|
| เปลี่ยนขนาด/รูปทรงกล่องชน (hitbox) ของเต่า บอร์ด ล้อ | `Scripts/Runtime/Player/TurtleController.cs` ส่วน `Build` (colliders) |
| เปลี่ยน hitbox ของกรวย ป้าย สายเคเบิล นก หิน ราว | `Scripts/Runtime/World/WorldGenerator.cs` ฟังก์ชัน `SpawnCone`, `SpawnSign` ฯลฯ |
| เต่ามีอนิเมชันหลายเฟรม (เช่น ตาเหลือกตอนตีลังกาตาม GDD) | ตอนนี้เต่าเป็นภาพเดียว ต้องเพิ่มการสลับเฟรมใน `TurtleController.Update` (ดูตัวอย่างการสลับ 2 เฟรมของนกใน `BirdFlyer`) |
| ท่าล้มแบบแยกชิ้นส่วน (ragdoll หลายชิ้น) | `TurtleController.Crash` (ตอนนี้เต่าก้อนเดียวหมุนกระเด้ง) |
| สีพื้นดิน/หญ้า | พื้นวาดด้วยโค้ด (ไม่ใช่ภาพ) แก้สีใน `WorldGenerator.BuildChunk` (`grassA`, `grassB`, `dirtTop`, `dirtBot`) |
| เพิ่มสกินใหม่ | เพิ่มบรรทัดใน `Scripts/Runtime/Upgrades/SkinDatabase.cs` แล้ววาง `turtle_{id}.png` |
| ฟอนต์/ภาษาไทยใน UI | `UIFactory.DefaultFont` |

## เสียง

ใช้หลักเดียวกัน: วางไฟล์เสียง (wav/ogg/mp3) ชื่อเดียวกันใน `Assets/_Project/Resources/Audio/`
`coin, part, perfect, rough, flip, boost, hit, crash, click, buy, deny, thrust` (เสียงไอพ่น ควรวนต่อกันได้), `music_run` (เพลงวน)

## เคล็ดลับ

- เก็บไฟล์ต้นฉบับ (.aseprite, .psd) ไว้นอก `Resources` เช่น `Assets/_Project/Art/Source/` เพราะทุกอย่างใน `Resources` ถูกใส่ลงในเกม
- วาดเส้นขอบเข้ม 1px รอบตัวละครเหมือนต้นแบบ จะอ่านง่ายบนฉากหลังสว่าง
- ทดสอบบนจอ 16:9 (Game view ตั้ง 1920×1080) เพราะเกมเล่นแนวนอน
- commit ทั้งไฟล์ `.png` และ `.png.meta` ขึ้น git ด้วยเสมอ
